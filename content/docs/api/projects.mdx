## List projects

```http
GET /api/v1/projects
Authorization: Bearer <admin-key>
```

**Response**

```json
{
  "data": [
    {
      "id": "proj_abc123",
      "name": "My App",
      "slug": "my-app",
      "bucketName": "my-app",
      "visibility": "private",
      "createdAt": "2025-01-01T00:00:00.000Z"
    }
  ]
}
```

## Create project

```http
POST /api/v1/projects
Authorization: Bearer <admin-key>
Content-Type: application/json

{
  "name": "My App",
  "visibility": "private"
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `name` | string | ✅ | Human-readable name. Slug is auto-derived. |
| `visibility` | `"public"` \| `"private"` | ✅ | Controls bucket policy and delivery auth. |

The MinIO bucket is created automatically on project creation.

## Update project

```http
PATCH /api/v1/projects/:id
Authorization: Bearer <admin-key>
Content-Type: application/json

{
  "name": "New Name",
  "visibility": "public",
  "deliveryCacheEnabled": true,
  "deliveryCacheTtlSeconds": 600,
  "allowedOrigins": ["https://app.example.com", "https://admin.example.com"]
}
```

| Field | Type | Description |
|---|---|---|
| `name` | string | Human-readable name. |
| `visibility` | `"public"` \| `"private"` | Changes bucket policy immediately. |
| `deliveryCacheEnabled` | boolean | Whether to emit `Cache-Control` headers on transformed delivery responses. Default: `true`. |
| `deliveryCacheTtlSeconds` | integer | `max-age` value in seconds for `Cache-Control` headers. Default: `300`. Set to `0` to disable caching while keeping the flag enabled. |
| `allowedOrigins` | string[] | List of CORS origins allowed to make cross-origin requests to this project's delivery and API endpoints. Each must be a full URL including protocol (e.g., `https://app.example.com`). |

Changing `visibility` updates the MinIO bucket policy immediately.

`Cache-Control` headers are emitted as `public, max-age=<ttl>` for unauthenticated requests, and `private, max-age=<ttl>` when an `Authorization` header is present.

## Delete project

```http
DELETE /api/v1/projects/:id
Authorization: Bearer <admin-key>
```

Deletes the project record. **Does not delete the MinIO bucket or its contents** — you must
clean that up manually via the MinIO console or the files API.
