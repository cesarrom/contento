---
title: Sign Upload URL
description: Generate a signed backend PUT URL so clients upload through Contento.
---

Request a signed URL from Contento and upload to that URL. Contento will proxy the upload
to internal MinIO.

## Endpoint

```http
POST /api/v1/projects/:id/sign/upload
Authorization: Bearer <write-key>
Content-Type: application/json

{
  "path": "/images/photo.jpg",
  "contentType": "image/jpeg",
  "expiresIn": 3600
}
```

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `path` | string | ✅ | — | Object key in the bucket. Leading `/` is stripped. |
| `contentType` | string | ✅ | — | MIME type. Must match the file being uploaded. |
| `expiresIn` | number | ❌ | `3600` | Seconds until the presigned URL expires. |

## Response

```json
{
  "data": {
    "url": "https://contento.yourdomain.com/api/v1/projects/<id>/upload?path=images/photo.jpg&token=...",
    "method": "PUT",
    "expiresAt": "2025-06-01T13:00:00.000Z"
  }
}
```

## Client upload

```js
const { data } = await fetch("/api/v1/projects/<id>/sign/upload", {
  method: "POST",
  headers: { "Authorization": "Bearer <key>", "Content-Type": "application/json" },
  body: JSON.stringify({ path: "/images/photo.jpg", contentType: "image/jpeg" }),
}).then(r => r.json());

await fetch(data.url, {
  method: "PUT",
  headers: { "Content-Type": "image/jpeg" },
  body: file,
});
```
